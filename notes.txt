solutions of prop drilling:
1- component composition: Instead of passing props down through multiple layers of components, you can compose components together and pass props directly to the components that need them.
2- Context API: React's Context API allows you to create a context and provide it to components that need access to certain data, eliminating the need for prop drilling.

=> useReducer hook: The useReducer hook is a more advanced state management solution that can be used in conjunction with the Context API. It allows you to manage complex state logic and actions in a more organized way. You can define a reducer function that handles different actions and updates the state accordingly, and then use the useReducer hook to manage the state in your context provider. This can help reduce prop drilling and make your code more maintainable.
=> how to use it in the shopping-cart-context.js file:
- import useReducer from react
- the useReducer hook takes two arguments: a reducer function and an initial state. The reducer function defines how the state should change based on different actions, while the initial state is the starting point for the state.
- it returns an array with two elements: the current state and a dispatch function that can be used to trigger actions and update the state.
- define the reducer function that takes the current state and an action as arguments, and returns a new state based on the action type. The reducer function should handle different action types and update the state accordingly.
- when we dispatch an action we pass an object with a type property that indicates the action being performed, and payload property that contains any additional data needed to update the state. The reducer function will use the action type and payload to determine how to update the state.
